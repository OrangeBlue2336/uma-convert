# UmaConvert

**우마무스메 게임 파일에서 추출한 텍스처를 브라우저에서 PNG와 스프라이트 이미지로 변환하는 비공식 도구입니다.**
파일은 서버로 업로드되지 않으며, 변환은 사용 중인 브라우저 안에서만 이루어집니다.

[웹에서 사용하기](https://orangeblue2336.github.io/uma-convert/) · [문제 제보](https://github.com/OrangeBlue2336/uma-convert/issues)

## 할 수 있는 일

현재 사용할 수 있는 도구는 **스프라이트 변환기**입니다.

- `heroes_tex`, `note_tex`처럼 확장자가 없는 Unity 텍스처 파일을 엽니다.
- 텍스처 전체를 한 장의 PNG로 저장합니다.
- 텍스처 안의 스프라이트 조각을 각각의 PNG로 저장하거나, 한 번에 ZIP으로 내려받습니다.
- 여러 텍스처가 들어 있는 파일은 목록에서 원하는 텍스처를 골라 변환합니다.

라이브 가사 변환기는 준비 중입니다.

## 사용 방법

1. [UmaConvert 웹사이트](https://orangeblue2336.github.io/uma-convert/)에서 **스프라이트**를 선택합니다.
2. 게임 폴더에서 꺼낸 텍스처 파일을 화면에 끌어다 놓거나 **파일 선택**을 누릅니다.
3. 변환이 끝나면 결과 화면에서 이미지를 확인합니다. 조각 경계를 켜거나 끄고, 목록에서 조각을 검색할 수 있습니다.
4. 필요한 저장 방식을 선택합니다.
   - **PNG 저장**: 텍스처 전체를 PNG 한 장으로 저장합니다.
   - **조각 ZIP 저장**: 모든 스프라이트 조각을 PNG 파일로 묶어 ZIP으로 저장합니다.
   - 조각 목록의 **저장**: 선택한 조각만 PNG로 저장합니다.

## 지원 범위

| 구분 | 지원 내용 |
| --- | --- |
| 번들 | UnityFS, LZ4 계열 압축, Unity 2017 이상 |
| 텍스처 형식 | DXT1, DXT5, RGBA32, ARGB32, BGRA32, RGB24, RGB565, RGBA4444, ARGB4444, Alpha8, R8 |
| 결과 | 전체 텍스처 PNG, 스프라이트별 PNG, 스프라이트 PNG ZIP |

아래 형식은 아직 지원하지 않습니다: BC7, ETC/ETC2, ASTC, PVRTC, Crunch 압축, LZMA 압축 번들, 암호화된 파일. 지원하지 않는 파일을 열면 브라우저에 이유를 안내합니다.

## 잘 되지 않을 때

- **파일을 열 수 없어요.** 게임에서 추출한 UnityFS 텍스처 파일인지 확인해 주세요. 암호화되었거나 LZMA로 압축된 파일은 현재 열 수 없습니다.
- **"Texture2D가 없습니다"라는 메시지가 보여요.** 선택한 파일에 변환할 텍스처가 없을 수 있습니다. `heroes_tex`, `note_tex` 같은 텍스처 파일을 다시 선택해 보세요.
- **PNG 저장이 안 돼요.** 최신 Chrome, Edge, Firefox 같은 최신 브라우저에서 다시 시도해 주세요.
- **결과가 기대와 달라요.** 사용한 파일의, 표시된 오류 문구, 가능하면 화면 캡처를 함께 [Issue](https://github.com/OrangeBlue2336/uma-convert/issues)에 남겨 주세요.

## 개인정보 및 저작권

파일 변환은 브라우저 내부에서 처리되며, 특정 서버로 파일을 전송하지 않습니다. 다만 브라우저 확장 프로그램이나 네트워크 환경은 이 프로젝트의 통제 범위 밖입니다.

이 프로젝트는 팬이 만든 비공식 도구입니다. 게임 리소스의 저작권은 각 권리자에게 있습니다.
